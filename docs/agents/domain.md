# Domain Docs

This repository uses a single domain context.

## Before exploring

Read these files when they exist:

- `CONTEXT.md` at the repository root
- ADRs under `docs/adr/` that affect the area being changed

Proceed silently when they do not exist. Domain-modeling skills create them when terminology or durable decisions need to be recorded.

## Use the glossary vocabulary

Use terms exactly as defined in `CONTEXT.md` in issue titles, specifications, tests, and code. Avoid introducing synonyms for established concepts.

If a required concept is absent, reconsider whether the term is needed or record the gap for domain modeling.

## Respect ADRs

Surface a conflict with an existing ADR explicitly instead of silently overriding it.
